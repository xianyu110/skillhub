### 如何解锁

1. 在 [https://skilloop.dev/zh/pricing](https://skilloop.dev/zh/pricing?utm_source=github&utm_medium=readme) 订阅或购买终身版。
2. 登录后打开 Skill 页下载 ZIP（或用 API 密钥请求 `/api/skills/<slug>/download`）。
3. 解压到 `~/.claude/skills/<slug>/` 或 `~/.agents/skills/<slug>/`。

目录中的开源 Skill 仍然免费，并从各自上游仓库安装。
