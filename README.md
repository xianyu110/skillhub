### How to unlock

1. Subscribe or buy Lifetime on [https://skilloop.dev/pricing](https://skilloop.dev/pricing?utm_source=github&utm_medium=readme).
2. Sign in, open a skill page, download the ZIP (or use an API key with `/api/skills/<slug>/download`).
3. Unzip into `~/.claude/skills/<slug>/` or `~/.agents/skills/<slug>/`.

Open-source skills in the catalog remain free and install from their upstream repos.
